# Document Organize Skill

📁 OpenClaw skill for creating organized document folder structures.

## Overview

Automatically creates project and practice subdirectories for organizing your work.

## Usage

When user mentions: `文档整理`, `创建文件夹`, `项目结构`, `练习目录`

## Features

- Creates `project/` and `practice/` directory structure
- Organized workspace setup

## Requirements

- OpenClaw agent
- File system write access

## Installation

This skill is managed by OpenClaw. Install via:
```bash
openclaw skills install document-organize
```
